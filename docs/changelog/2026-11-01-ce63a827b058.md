# 2026-11-01 菜单栏图标与隐藏/显示

## 目标与验收
- 便签可以整体隐藏（游戏时不挡画面），再从菜单栏找回。
- 菜单栏有图标：菜单含 Show/Hide Notes、Launch at Login、Quit。
- 右键小圆点／标题栏菜单也有 Hide Notes。
- 隐藏时菜单栏图标仍在，是唯一的恢复入口。

## 改动范围
- `main.swift`：`NoteController.setHidden(_:)`；`AppDelegate` 新增状态栏图标、`toggleVisibility`，菜单随打开刷新标题和勾选。
- `README.md`：菜单栏说明更新（原文写"no menu bar icon"）。
- 未提交（非本次任务要求）。

## 验证结果（已自验）
- `./build.sh` 构建通过。
- 用 `FLOATNOTE_PROFILE=dev` 实际启动，通过 System Events 操作：
  - 点菜单栏图标，菜单项为 Hide Notes / Launch at Login / Quit。
  - 点 Hide Notes：浮窗窗口数 1 → 0，菜单标题变为 Show Notes。
  - 点 Show Notes：窗口数恢复为 1，截图确认浮窗出现在 Steam 窗口上方。
  - 点 Quit：dev 实例正常退出。
- 未验证：右键小圆点的 Hide Notes 项（只改了代码，未实际右键点击）；全屏游戏上方的表现。

## 问题与下一步
- 隐藏状态不持久化：重启后会重新显示。
- 没有全局快捷键（README 中仍列为未来想法）。
- 运行中的旧实例仍是旧版本，需要退出后重新打开 `FloatNote.app` 才会出现菜单栏图标。
